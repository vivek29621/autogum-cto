# AutoGum Mascot Logo — Master Prompt

> Create a premium mascot logo for an AI agent company called AutoGum.

## IMPORTANT: Use the attached/reference images specifically for the bubble-gum action and facial expression. Do not reinterpret the concept as slime, goo, paint, or an explosion.

## The mascot
A small, slim, cute chibi AI agent, seated in a compact pose. Body relatively small and lightweight, normal slim robotic proportions. NOT fat, bulky, muscular, oversized, or teddy-bear shaped.

The agent looks like a capable AI coding/terminal agent:
- Small futuristic robot
- White/silver smooth helmet
- Black glossy face visor
- Simple friendly smiling face visible on the visor
- Small black hoodie
- Compact robotic arms and legs
- Clean minimal silhouette
- Subtle terminal-inspired details
- No unnecessary accessories

## THE MAIN IDEA: AUTOGUM
The agent has been chewing bubble gum. The bubble has been blown and is now partially stuck to the agent's face as it bursts.

Reference the attached human/anime bubble-gum images for the physical action:
- A partially inflated bubble still visibly attached to the mouth/face
- The bubble has collapsed/burst unevenly
- Part of the gum remains stretched across the face
- Sticky gum strands connect the remaining bubble to the face
- A few small pieces of gum stick to the visor/helmet
- Some tiny gum droplets/stretch marks extend outward
- Gum looks like chewed bubble gum: thick, elastic, glossy, sticky
- Clearly looks like the agent has been chewing it
- Burst is playful and slightly messy, NOT violent
- The cute smiling face remains recognizable

The gum is stuck to the agent because the agent itself "sticks" to everything it works on. The gum is a visual metaphor for **"sticks to tasks."**

## COLOR
- Black + white/silver + terminal green only
- Chewing gum is glossy terminal green (NOT pink)
- Natural computer-terminal green, not fluorescent slime green
- NO pink, purple, blue, rainbow, or slime-like neon liquid

## COMPOSITION
- No circular badge, no ring, no text, no company name, no "AUTOGUM", no "CTO"
- No laptop, no UI panels, no task cards, no background objects
- Just the small seated AI agent mascot on a clean black background
- Plenty of negative space — must work as: AI agent avatar, GitHub avatar, X profile picture, Discord/Telegram avatar, favicon, website logo, app icon, company branding

## STYLE
- Premium modern AI startup mascot
- Clean, polished 3D/vector hybrid illustration
- Cute but technically sophisticated
- Minimal enough to recognize at 32x32px, detailed enough at large size
- Feels like a real AI agent character, not a generic cartoon robot
- Do not change the seated pose. Do not make the character fat. Do not replace chewing gum with slime. The gum stuck to the face is the central idea.
